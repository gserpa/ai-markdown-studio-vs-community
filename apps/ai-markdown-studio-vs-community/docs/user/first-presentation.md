# Create your first presentation

1. Create a file named `first-presentation.md` with the content below.
2. Open it in Community. The `document: presentation` front matter selects slide preview.
3. Move between slides, choose a bundled presentation theme, and inspect the notes below the second slide.
4. Use **Export to HTML** to share the presentation as a browser file.

```markdown
---
document: presentation
title: My first presentation
theme: galaxy
---

<!--slide: cover-->
# My first presentation

A short introduction.

---

<!--slide: content-->
# Next steps

- Show the result.
- Explain what happens next.

<!--notes: Mention the next review date. -->
```

See the [MPS authoring reference](authoring-reference.md#presentation-files) for slide types, separators, and notes. The [user guide](user-guide.md#presentation-preview) covers preview controls and themes.
